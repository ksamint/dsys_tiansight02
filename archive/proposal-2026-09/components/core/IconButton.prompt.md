Icon-only action for header utilities, row actions and modal dismissal — never for a primary CTA.

```jsx
<IconButton icon={<Icon name="search" />} label="搜索" />
<IconButton icon={<Icon name="x" />} label="关闭" variant="outline" />
```

`quiet` (default) hovers to parchment-100; `solid` is bronze-filled. Sizes 28/34/42px.
