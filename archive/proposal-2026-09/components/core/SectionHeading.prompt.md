Opens every section on the site and every block in a report page. Keeps the mandatory copy order.

```jsx
<SectionHeading
  eyebrow="以样张为证"
  title="一份报告，就是一份决策文件"
  subtitle="每条结论具备四要素：证据、利润影响、执行动作、验收指标。"
  action={<Button variant="ghost" size="sm">报告样张</Button>} />
```

`tone="inverse"` on the ink closing band. `align="center"` only for the final CTA.
