00 · Operating rules

总则

离线版本 v0.7 · source: brand/guide.md · 实时更新

Always pale

底色永远是淡墨纸

页面底色 #F4F0E7，内容层 #FFFDF8。不用纯白，不用纯黑。

Ink first

素墨是主色

#EFE6D2 承载色块与关键操作；玄墨承载文字；土金给结构；朱红只作印记，≤ 5%。

Serif everywhere

通篇宋体

中文思源宋体，英文 Noto Serif 大写字距排版。等宽字体只用于色值、代码、数据、价格。

Bilingual

中文为主，英文为注

每个中文标题配一行大写英文题注，颜色深金。中文不用斜体，强调用字重或明金。

No slop

不许的事

  • 装饰性渐变、表情符号
  • 圆角卡片加左侧色条
  • Inter / Roboto，或任何无衬线回退
  • 手绘复杂图形；只画圆与线
Falsifiable

凡判断皆可被证伪

这份规范是活文档。任何结论一旦被门店真实数据推翻，即刻修订。

Decisions taken · v0.7 rulings

已定与待定

以下为本基础层落实指南时所作的判断，以及需要品牌方确认的事项。凡判断皆可被推翻。

主按钮的边界

素墨与淡墨纸对比仅 1.09。主按钮以土金 34% 描边定义边界，悬停转宣纸底。待确认：是否接受描边，或改用玄墨实心按钮作主操作。

明金的字号下限

明金在浅底上 1.9 : 1。基础层限定为 28px 以上或纯装饰；关键数字用等宽 40px。待确认：标语「智慧领航者」在 18px 时是否保留明金。

土金与深金同值

指南 v0.6 中 --gold 与 --gold-deep 均为 #76551F。两者均保留为独立令牌，以便日后分化。待确认：深金是否应另取值。

罗盘印与官方标志

指南描述主标志为「罗盘环 + 侍」，而发布的标志文件是圆环内「侍天」印章。基础层以发布文件为准，罗盘只作水印。待确认。

图表语义色

导出方案的增长 / 流失 / 关注 / 中性四色不在指南内。基础层只提供明金 · 玄墨 · 朱红三序列。待确认：报告是否需要更多语义色。

字体授权与托管

Noto Serif SC、Noto Serif、IBM Plex Mono 均为 OFL 授权，可自托管。待提供：字体子集策略与目标环境，以定 fonts.css。

首个消费方

官网、报告、销售提案三者中，建议先迁移官网：它是入口，组件覆盖最广。待确认：优先级与构建方式。

文案与价格

本页价格与客户引述均取自指南或样例，发布前须核实。伙伴名单只用指南与导出方案中的既有名称。
