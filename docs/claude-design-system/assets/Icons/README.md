侍天's own 17 hairline glyphs, one SVG each, split from the repo's `ts-*` sprite (`brand/icons.svg`). Geometry: 24×24 box, stroke 1.5, no fills, square caps and miter joins (foundation `.ts-icon`). Ink: `charcoal` #17130D. An `<img>` cannot recolor them, so in UI use the `Icon` component, which draws the same paths in `currentColor`. Show them at 18–20px in UI and 24px in feature blocks. `compass` is the brand motif and the default choice for navigation or direction. No emoji, anywhere.
